# PANTECHNOSYNI Atlas Web Design

## Goal

Turn the tested Synthesis Atlas into a public, accessible, responsive product surface with real local interactions.

## Architecture

A deterministic generator projects the canonical Node atlas into a browser-safe ESM data module. A pure browser model manages filtering, discipline inspection, path endpoints, bounded synthesis selection, and session-only brief previews. A static HTML/CSS/JS interface consumes the model without network calls or browser persistence.

## Visual direction

The interface uses a modern Mediterranean editorial system: warm near-white canvas, deep ink text, muted stone dividers, restrained cobalt and terracotta accents, serif display typography with clean system UI text, open rails and lists instead of nested card grids, and a subtle line-based network motif. The desktop layout uses a compact command header, domain rail, atlas workspace, and inspector. Mobile becomes a clear vertical reading and interaction order.

## Success criteria

- generated browser data exactly matches the canonical atlas digest and graph;
- search, domain filtering, discipline selection, path finding, and brief preview update real local state;
- synthesis selection is limited to two through six disciplines;
- every graph interaction has a readable text alternative;
- keyboard focus, live status, reduced motion, and mobile layout are explicit;
- no network, storage, provider call, private data, external write, deployment, or automatic claim is introduced.
