# Contributing

Contributions should strengthen PANTECHNOSYNI as an independent public synthesis system.

1. Open a focused branch.
2. Keep the change public-safe and free of credentials or private data.
3. Add or update tests before implementation.
4. Run `npm run check`.
5. Explain product ownership, evidence, accessibility, and rollback impact in the pull request.

Do not import another repository wholesale, add dependencies without a clear need, or convert plans and metadata into unsupported capability claims.
