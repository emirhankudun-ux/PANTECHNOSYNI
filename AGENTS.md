# PANTECHNOSYNI Repository Constitution

Read this file before changing the repository.

## Identity

PANTECHNOSYNI (ΠΑΝΤΕΧΝΟΣΥΝΗ) is an independent public interdisciplinary synthesis system. Its role is to make relationships between creative practice, technology, science, knowledge, and human experience understandable and usable.

It is not a renamed copy of another project, a repository history dump, a generic AI dashboard, or a claim that every discipline has been automated.

## Authority boundaries

- This repository owns PANTECHNOSYNI-specific synthesis contracts, atlas data, public examples, documentation, and product surfaces.
- Other repositories remain sovereign and canonical for their own runtimes, private memory, research programs, and source history.
- Do not copy private files or import another repository wholesale.
- Interoperability must be explicit, public-safe, reversible, and contract-based.

## Engineering rules

- Work on focused branches and reviewable pull requests.
- Prefer dependency-free, portable modules until a dependency has clear product value.
- Write a failing test before implementing behavior.
- Keep data and derived views deterministic when the contract says deterministic.
- Update documentation whenever public behavior changes.
- Do not push directly to `main` unless the owner explicitly authorizes it.
- Never force-push or rewrite shared history.

## Truth and safety

Never commit credentials, tokens, private keys, private hosts, client data, personal memory, or unlicensed assets. Never present metadata, plans, local fixtures, or generated text as live AI, scientific proof, production readiness, or independent verification.

Provider calls, MCP authentication, deployment, publication automation, external writes, and destructive synchronization require explicit owner approval and their own evidence.

## Completion standard

A change is complete only when its identity and ownership are clear, tests pass, public/private boundaries are reviewed, documentation is current, and verification is reported honestly.
