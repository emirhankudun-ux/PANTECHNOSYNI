# Security Policy

## Supported surface

The current supported surface is the tracked public repository, its dependency-free Node modules, tests, and GitHub Actions workflow.

## Reporting

Report suspected vulnerabilities privately through GitHub’s security-reporting features when available. Do not publish credentials, exploit details, private hosts, or personal data in a public issue.

## Current boundaries

The foundation performs no provider calls, MCP authentication, remote execution, external writes, or deployment. The core library reads only the public atlas data supplied to it.
